# openendo.org design review — 2026-10-28 (Percival)

Captured every page at 1440 and 375 wide. P0 first.

## Verdict
The palette and fonts are right. It reads as AI-made for three reasons: (1) the copy keeps describing itself and ends nearly every block with a negation ("It is not a new care pathway." / "It does not diagnose you." / "not a prescription"); (2) every page uses the same template (eyebrow, yellow dash, huge serif H1 with a full stop, grey sub, chips); (3) no human is visible anywhere. Find care and symptom help are buried.

## P0: findability
1. The main nav is `hidden xl:flex`, so it disappears below 1280px and iPads and most laptops only get a hamburger. Use `md:flex`. On mobile, keep a visible "Find care" text button in the header beside the menu icon, and move Dark and Dansk into the menu.
2. The homepage needs two large task tiles above the fold, replacing "Read the guides / This week's evidence":
   - "I think I might have endometriosis" goes to Symptoms, then when to see a doctor, then a symptom diary.
   - "Find care in Denmark" goes to /access with DK preselected.
   Make each at least 120px tall (full width on mobile) with one plain sentence. Evidence and data move below.
3. /access opens on an empty select with a disabled button, which is a dead end. Preselect DK (from the `da.*` route or the default) and render results straight away. Order: 1) your GP / egen læge, 2) referral path, 3) specialist centres with phone and link, 4) reimbursed medicines, 5) patient organisations. "Last reviewed 2026-09-07" is seven weeks old, so re-review it or show the stale state. Retitle "Where you can actually get help." to "Find care".
4. There is no managing-symptoms guide. Add /learn/managing-symptoms (EN and DA):
   - pain relief options as the guidelines name them
   - heat and TENS, each labelled with its evidence strength
   - a flare plan and a symptom diary
   - talking to work or school
   Link it from Symptoms, Living and home. Also add a printable "Bring this to your appointment" one-pager (the diary plus the NICE suspicion list as checkboxes).
5. Symptoms isn't scannable. The NICE paragraph is one semicolon chain of seven items. Make it a checklist: one line per symptom, a bold short label, a muted detail line. Then add a "When to see a doctor" callout (info colour) and "Seek urgent care if…" (danger colour, only if WHO or NICE state it). "In short" currently describes the page; make it the answer, e.g. "Common signs are periods painful enough to stop daily life, pain during or after sex, painful bowel movements or peeing around your period, and trouble getting pregnant. A normal scan doesn't rule it out."
6. Names collide: "Find care", "Care finder" in the footer, and /find titled "Find a page". Rename /find to "Site index" and link it only from the footer. "Find care" is the one name for /access.

## Diagram visual spec
Character: a careful clinician's whiteboard redrawn by an information designer. Flat, line-led, lots of whitespace. No anatomy renders, gradients, 3D, glossy organs, stock icons or silhouettes. The only drawing allowed is one optional pelvis outline (single line, no fill) for "where it occurs".

Construction:
- Inline SVG from JSON (EN and DA from the same data), so text is real and selectable. Colours via CSS variables and currentColor only.
- Strokes: 1.5px structure, 2px primary path, 1px hairlines. Round caps and joins. Node radius 8 (`--radius-md`).
- Nodes: `--surface` fill, 1.5px `--border-strong` stroke. Title max 4 words, Atkinson Hyperlegible Next 15–16px, sentence case. Detail line 14px `--ink-muted`.
- Connectors: 1.5px `--ink-muted`, 6px open chevron arrowheads, orthogonal routing. Diagonal fan-out appears only in the mechanisms to symptoms diagram (see below).

### Connectors (rest)
Diagonal fan-out only in mechanisms -> symptoms: lines leave a node from one shared point on its right edge, spread as straight lines, turn 90° just before each target. More than 4 targets from one node = split the diagram. No curves anywhere.

### Colour roles
- `--primary`: main path and established findings.
- `--ink`, `--ink-muted`: structure.
- `--info`: "your next step" nodes.
- `--caution`, `--danger`: seek-care nodes only.
- Ribbon yellow never appears.

### Icons
None by default. Exception: diagnosis-pathway step types get a 16px Lucide line glyph (stethoscope, scan, scope), 1.5px stroke, always beside its text label.

### Frame
Max width 720px. Title is an h3 in Source Serif 4 above. Below: one-sentence "what this shows" caption in `--ink-muted`.

### Evidence strength (same four words as editorial policy; line style + word, never colour alone)
- Established: solid 2px `--primary` + 3px `--primary` left bar on the node.
- Likely: solid 1.5px `--ink`.
- Uncertain: dashed 4/4, 1.5px `--ink-muted`.
- Not yet shown: dotted 1/4, 1.5px `--ink-subtle`, muted node text.
Each node/edge with a strength carries a 12px pill (`--surface-2` fill, 1px border) with the word. One legend top-right with the four line samples.

Leading theories: a list, not a flow. Row = theory name, 4-step scale (four 10×10 squares filled to level + the word), one sentence. No percentages.

Known vs not known: two columns, "Known" solid border, "Not yet known" dashed border. Open questions as plain sentences.

### Citations
- Every claim node: superscript number in `--primary` at end of its detail line, matching the page source list.
- Under the caption: Sources line, e.g. "1 WHO fact sheet, 15 Oct 2025 · 2 NICE NG73 1.5.8", then the diagram's last-reviewed date.
- Hover/focus a node highlights its sources in that line. Touch: tap opens a popover with source + strength; keyboard reachable, Esc closes.
- A claim with no source never goes in a diagram.

### Dark mode
Same SVG, only variables swap. Dashed/dotted lines must reach 3:1 non-text contrast against `--bg`; else go to 2px. No pure white fills; nodes use `--surface`.

### Mobile (<=600px)
- Never scale down. Flows re-lay vertically: top to bottom, full-width nodes, connectors point down. Text min 14px at 375px.
- Fan-out becomes a list: each mechanism with its symptoms indented, pills kept.
- Treatment map becomes stacked collapsible groups (Pain relief / Hormonal / Surgery / Fertility / Support), pills visible when collapsed.
- No horizontal scroll. Tap targets 44px.

### Accessibility
`role="img"`, aria-labelledby -> title + caption. "Show as text" toggle renders the same JSON as an ordered list or theories × strength table (also the print and screen-reader version). No animation needed; if any, 150ms opacity on highlight, none under reduced motion.

### Per diagram
1. How it develops: timeline, horizontal desktop / vertical mobile, strength line styles.
2. Leading theories: strength-scale list.
3. Mechanisms -> symptoms: three columns (mechanism, effect, symptom), fan-out, strength on edges, max 12 nodes.
4. Diagnosis pathway: history and diary -> exam -> ultrasound or MRI -> specialist -> laparoscopy where indicated. Side branch in `--info`: "Normal scan? It can still be endometriosis. Next step: …". Danish version uses the same component with the Danish path.
5. Treatment map: grouped, never ranked. Each option shows its strength + the guideline that names it (NICE / ESHRE).
6. Known vs not known: two columns.

**Fan-out (mechanisms diagram only):** edges leave one shared point on the node's right edge, run straight, and turn 90° just before each target. More than 4 targets from one node means split it. No curves anywhere. On mobile this becomes each mechanism with its symptoms indented below.

# Trials & funding chart spec
- **By country:** horizontal bars sorted descending, top 10 plus "Other countries (n)". Rows are 32px (44px on mobile). Labels sit in a 9rem column, 15px `--ink`. Bars are 10px `--primary`, right radius 2, with no track. The value goes after the bar in 14px mono with tabular figures. No axis or gridlines. Denmark always shows, in bold with a pill. "Show as table" replaces the duplicate table.
- **Denmark by status:** the same component, ordered by meaning: Recruiting, Not yet recruiting, Active, Completed, Terminated, Unknown. Recruiting uses `--primary`, Terminated uses `--caution`, the rest use `--ink-muted`. No ribbon yellow.
- **Papers per month:** columns, not a line, at 60% of slot width in `--primary`. The incomplete month is hatched or at 40% opacity and labelled "so far". One baseline, a value on top of each column, no y-axis. At 375px show the last 6 months.
- **All charts:** server-rendered inline SVG from the JSON. Bars need 3:1 contrast. No load animation. The empty state reads "No data in this snapshot" plus the date. If the snapshot is more than 10 days old, show a caution line: "Snapshot from …, update due."
